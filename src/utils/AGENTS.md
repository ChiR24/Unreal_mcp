# src/utils

Shared TypeScript utilities: security gates, path policy, logging, response shaping, deterministic ordering. Most paths depend on this layer, so keep it strict and dependency-light.

## WHERE TO LOOK
| Utility | File | Purpose |
|---------|------|---------|
| UE path security | `paths/path-security.ts`, `paths/content-path-policy.ts` | `sanitizePath()`; the shared content-root and secret-key vocabulary; the editor-reported content roots (`setEditorContentRoots` / `getContentRoots`) |
| Asset path sanitize | `validation/validation.ts` | `normalizeAndSanitizeAssetPath()` |
| Console command safety | `commands/command-validator.ts` + `console-command-policy-{rules,matching}.ts` | one evaluator; rules generated by `npm run headers:generate`, checked by `headers:check` |
| Output validation | `responses/response-validator.ts` | `wrapGatewayResponse()` against the `unreal` output schema |
| Bridge frame shape | `responses/automation-frame-normalization.ts` | one structured payload for both transports |
| Response text/content | `responses/response-content.ts` | summaries, image content |
| Logging | `logging/logger.ts`, `logging/log-redaction.ts` | structured stderr logging; image/secret redaction |
| Ordering | `serialization/ordering.ts` | byte-order comparison for generated artifacts (never `localeCompare`) |
| Safe JSON | `serialization/safe-json.ts` | clean values before returning/logging |
| Bounded stores | `collections/bounded.ts` | insertion-order eviction |
| INI reads | `config/ini-reader.ts` | project config values |
| Type guards | `validation/type-guards.ts` | narrowing `unknown`, coercing loose bridge reply fields |

## CONVENTIONS
- Allowed roots: `/Game`, `/Engine`, `/Script`, `/Temp`, `/Niagara`, the content mounts the connected editor reports (`bridge_ack.contentRoots`, kept current by `content_roots_changed`), plus sanitized `MCP_ADDITIONAL_PATH_PREFIXES`. File keys keep the static roots plus `/Saved` and `/tmp`. The plugin owns the `/Content` alias and re-checks every path.
- `CommandValidator.validate()` blocks multiline commands, `py`/`python`, `&&`, `||`, `;`, `|`, backticks, dangerous engine commands and shell/Python file access; the plugin re-checks.
- Prefer `unknown` plus type guards over casts.

## ANTI-PATTERNS
- A second path-root or console policy outside these files.
- Bypassing `CommandValidator` for a console action.
- Logging secrets, capability tokens or unbounded payloads.
- Writing to stdout from runtime utilities.
